# 用途

由 Codex 内置 `$imagegen` 生成虚构成年男性正面基准照，再以正面图为身份参考生成同一人的右侧面照。它们用于调用真实 Nano Banana 开发 API，验证参考图编辑、模型选择、身份保持、三视图编排和日志；不得计入 5 人×5 款正式真人评估。

# 最终提示词

正面：`photorealistic-natural`；虚构约 30 岁东亚成年男性，正视镜头、自然皮肤、无配饰、炭灰圆领 T 恤、极短 buzz cut；浅灰纯背景，头肩居中，柔和中性光；禁止文字、水印、裁发、三分之四角度和美颜。

右侧面：`identity-preserve`；以前一张侧面为身份/拍摄条件参考，只改变水平方向，使鼻尖朝图片左侧并保持严格 90 度侧面；保持身份、发型、衣服、背景、比例、裁切、光线和表情一致；禁止三分之四角度、文字、水印和新增配饰。

正面与当前右侧面均已通过产品默认 `CaptureValidator` 的真实 OpenCV 解码、尺寸、清晰度、单脸和方向检查，尺寸均为 1536×1024。

# 来源标记

所有使用这些图的会话、调用和报告必须记录 `source=synthetic_imagegen`。内置 imagegen 只负责测试输入，不是产品 provider，也不能替代 Nano Banana 的真实调用结果。
