# 首个开发任务专家路由

- 主责：`ai-engineer`
- 原因：当前首要风险是单一 Gemini 图像编辑调用、三视图确定性编排、失败/重试和真实调用记录。
- 咨询输入：批准 PRD v1.4.0、Python 3.13/Node 24 环境、缺失模型 Key 的事实。
- 结论：使用单进程 FastAPI、窄 provider 接口、内存状态、临时目录和 JSONL；fake 不构成第二候选模型；当前不需 PRD revision。
- 工程裁剪：专家建议 React/Vite；为符合用户“快速上马”目标，工程主流程进一步裁剪为由 FastAPI 直接提供原生页面，避免增加构建链。此裁剪不改变用户行为或验收标准。
- 当前阻塞：缺少 Key 只阻塞真实接口冒烟，不阻塞开发。
- 触发 PRD revision：换模型/供应商、放宽调用次数或超时、增加数据库/队列/外部访问/人工审核/自动语义门禁。
