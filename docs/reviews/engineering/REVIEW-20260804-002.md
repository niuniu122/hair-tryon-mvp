# 初审发现与关闭

1. Blocker：结束运行后，在途轮询或摄像头回调可能回写 ended 状态。通过 ended no-op、运行 epoch/sessionId 守卫和迟到流停止修复；复核 RESOLVED。
2. Medium：第 2 次重试提交后，旧的第 1 次快照可能重新启用重试。通过 attempts 与全局 generationStatus 单调保护修复；复核与独立复现均 RESOLVED。
3. Medium：session POST 成功但模型 PUT 失败时，前端可能继续使用与后端不一致的模型。通过确认模型后才挂载 session、失败 DELETE 回滚修复；复核 RESOLVED。
