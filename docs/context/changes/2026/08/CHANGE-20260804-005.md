# 文档变更

根据用户提供的双预览参考图，把前端呈现修订为顶部紧凑工具条、左输入舞台、右结果舞台和底部发型轨道。正面/右侧面输入与正面/右侧面/背面结果分别通过标签收进单一舞台；现有 API、模型、调度、数据和安全边界不变。

# 前后摘要

- 修改前：左侧工作流表单与采集卡，右侧并列三张结果卡。
- 修改后：两个同尺寸媒体舞台，左侧摄像头/冻结输入，右侧单一结果预览；底部横向五款发型，动态主按钮推进流程。
- 原因：匹配用户明确提供的前端呈现，并缩短内部团队完成一次试发的视觉路径。
- 影响：需要重新组织原生 HTML/CSS/JS 和 UI 状态测试；不修改后端 API、数据库、provider 或依赖。
- 审批影响：改变用户可见信息架构，v1.5.0 已于 `2026-08-04T17:35:29+08:00` 获用户明确批准，`development_authorized: true`。
