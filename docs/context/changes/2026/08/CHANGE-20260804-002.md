# 变更说明

- 修改前：v1.4.0 已批准固定单一官方 Gemini 模型，开发处于进行中。
- 修改后：v1.4.1 草案采用同一第三方的两个普通版 Nano Banana 模型，允许新运行首次生成前选择并在运行内锁定；调整供应商端点、密钥变量和超时口径。
- 原因：用户明确要求可更改模型，并提供了可用第三方接口。
- 影响：改变已批准 PRD 的模型、端点、超时、数据出境和 UI 行为，故 `development_authorized` 设为 `false`，后端与前端实现中断。
- 关联：验收新增 `AC-MODEL-01` 至 `AC-MODEL-04`；正式真人测试前必须轮换已暴露密钥。
- 恢复路径：只有用户解决隐私阻塞问题并明确重新输入“批准 PRD，开始开发”后，才能更新技术栈/架构并恢复实现。v1.4.0 不会自动恢复。
