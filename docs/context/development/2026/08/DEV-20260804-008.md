# 修复内容

- 摄像头错误归一化：数字 DOMException code 不再透出，NotFound/无设备统一映射为 `camera_unavailable`，拒绝权限映射为 `camera_permission_denied`。
- 结束竞态：状态层拒绝 ended 后的生成快照；运行 epoch 与 sessionId 守卫轮询、摄像头、采集、生成、重试和模型 PUT 的迟到回调；结束操作在 DELETE 前清轮询并停流。
- 摄像头迟到流：媒体流在确认仍属于当前运行后才成为活动流；结束后返回的流立即停止。
- 重试单调性：低 attempts 的旧快照不能覆盖第 2 次提交后的状态；旧快照也不能把全局生成状态从 running 回滚为 partial_failure。
- 模型原子性：新 session 只有在后端确认所选模型后才挂载到前端；模型确认失败会尝试 DELETE 回滚。
