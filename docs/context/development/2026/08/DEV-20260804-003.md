# 查询结论

按用户提供的第三方 Nano Banana 文档与密钥做无真人数据探测。密钥未写入项目文件、日志或 Git；生成结果未落盘。

- 文档站：`https://bananapro.aigenmedia.art/docs`。
- 兼容端点：`POST /api/gemini/v1beta/models/{model}:generateContent`，支持 Bearer、`x-goog-api-key`、Base64/URL 参考图和最多 14 张参考图。
- `gemini-3-pro-image-preview` 纯文生图返回 HTTP 200、有效 PNG、模型版本和 usage。
- 同模型携带程序生成的 Base64 参考图做编辑，返回 HTTP 200、新的有效 PNG、模型版本和 usage。

结论：该通道技术上能生成和编辑图像，适合后续候选接入；但它改变了批准 PRD 的供应商端点、模型 ID（`gemini-3-pro-image-preview` 而非 `gemini-3.1-flash-image`）和可能的超时契约。当前不得静默接入；若用户确定采用，进入轻量 `prd_revision` 并重新批准。
