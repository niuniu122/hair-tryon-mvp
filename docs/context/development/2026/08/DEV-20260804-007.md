# 开发记录

## 路由与设计依据

- 主责角色为 Frontend Developer；批准范围只改变 Web 前端信息架构、交互状态和视觉呈现，不改变 API、数据库或 provider。
- 采用克制的内部工具界面：白色工作区、深色媒体舞台、蓝色仅用于唯一主动作，避免卡片堆叠。
- 保留同意门禁、参与者限制、模型选择与首次生成后锁定、Fake provider 持续警示、局部结果、单视图一次重试、背面 AI 推测和结束清理语义。

## 增删改查

- 改：旧纵向步骤页重组为紧凑顶部工具栏、等尺寸双舞台、底部横向五发型和单一动态主按钮。
- 增：输入正面/右侧面页签，结果正面/右侧面/背面页签；结果正侧面同步对应输入，背面保留最近真实输入并显示“本次未采集背面”。
- 增：页签 roving tabindex、方向键/Home/End 导航、动态 `aria-labelledby`、局部采集错误、重新采集和结果局部重试。
- 改：状态机增加摄像头就绪、活动输入/结果、手动结果选择、采集错误和重采准备；第一个成功结果只在用户尚未手动选结果页签时自动切换。
- 删：旧页面内分散的高强调会话、摄像头、采集和生成按钮，由唯一主按钮按固定序列推进；结束运行保留为次级动作。
- 查：核对现有 API 路由和返回字段，确认模型 PUT、采集、生成轮询、重试、图片读取和 DELETE 清理契约无需改变。
